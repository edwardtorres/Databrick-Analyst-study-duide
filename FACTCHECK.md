## Things you may have already learned wrong

### Answers that changed

| # | Question | What the app used to say | What the docs say now |
|---|---|---|---|
| 1 | **Ch 7, "Why should a trusted asset be parameterized?"** (c7-q-parameterized) | Parameters only make a trusted asset reusable; "Parameters are required for the Trusted label" was marked **wrong**. | Trusted assets are **only** parameterized example queries and Unity Catalog SQL functions. A static example query is **not** a trusted asset and doesn't give a verified answer. The correct option now says so. |
| 2 | **Ch 5, "After setting CLUSTER BY on an existing table, how does existing data become clustered?"** (c5-q-liquid-optimize) | Plain `OPTIMIZE` clusters the existing data incrementally. | Enabling clustering **does not recluster data already written**. Run **`OPTIMIZE table FULL`** once (and again after changing keys); after that, routine `OPTIMIZE` (or predictive optimization) clusters new data incrementally. |

### Facts in lessons that were wrong or outdated (correct options unchanged)

- **Genie (Ch 7):** the warehouse runs on the **space author's embedded credentials** (users need no warehouse permission), while data access is checked as **the asking user**. Data they can't access comes back as an **empty response**, not a permission error.
- **Genie (Ch 7):** **CAN VIEW and CAN RUN are identical** on a space. The tab is **Monitor** (needs CAN MANAGE). Feedback is **"Is this correct?" → Yes / Fix it / Request review**, not thumbs up/down. Responses from trusted assets are called **verified answers**. Limits: up to **50** tables (aim for **five or fewer**) and **100** instructions.
- **Dashboards (Ch 6):** the publish options are now named **Share data permissions** (default; formerly "embedded credentials") and **Individual data permissions**. **Cross-filtering** applies to visualizations that use the **same dataset**. **Alert states** are OK / TRIGGERED / ERROR, and conditions can **aggregate** a column (SUM, AVERAGE).
- **Photon (Ch 5):** Photon doesn't support **any UDFs** (not only Python/Scala ones). "Query Insights" appear in the UI as **performance insights**.
- **Result cache (Ch 5):** entries live up to **24 hours**. On serverless there is also a **remote result cache** shared by all warehouses in the workspace that survives restarts.
- **Uploads (Ch 3):** the UI upload accepts **CSV, TSV, JSON, Avro, Parquet and text**, not XML or Excel. Limits are up to **10 files, under 2 GB**, and **"First row contains the header" is on by default**.
- **Auto Loader (Ch 3):** for **JSON, CSV and XML, columns are inferred as STRING** by default (`cloudFiles.inferColumnTypes` changes that). It samples the first 50 GB or 1,000 files.
- **Ownership (Ch 9):** ownership doesn't inherit, but **catalog and schema owners can manage all child objects**. Grants can come from the **object owner, the parent catalog/schema owner, a MANAGE holder, or a metastore admin**. **ALL PRIVILEGES does not include MANAGE.**
- **Marketplace (Ch 1):** listings are datasets, notebooks, AI models, **apps and MCP servers**; "solution accelerators" are no longer listed.
- **Renames (all chapters):** the exam guide still uses the old names, so the app keeps them and shows the new ones beside them.
  - Delta Live Tables → **Lakeflow pipelines**
  - Databricks Assistant → **Genie Code**
  - Genie spaces → **Genie Agents**
  - Delta Sharing → **OpenSharing** (and open sharing → "Databricks-to-Open")
  - Vector Search → **AI Search**
  - DatabricksIQ → **Databricks AI assistive features**
  - APPLY CHANGES → **AUTO CDC**
